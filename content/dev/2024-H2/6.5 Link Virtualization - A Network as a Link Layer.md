# 6.5 Link Virtualization: A Network as a Link Layer


> 💡 The goal of MPLS is not to abandon the destination-based IP datagram forwarding infrastructure in favor of one based on fixed-length labels and virtual circuits. Instead, it **augments the destination-based IP datagram forwarding infrastructure by selectively labeling datagrams where possible, so that routers can forward them based on fixed-length labels**.

### MPLS Header

<p align="center"><img width="700" alt="MPLS header" src="https://user-images.githubusercontent.com/76640167/214874099-42e288e6-687a-46b6-a313-546fcdeed767.png">

A link-layer frame handled by an MPLS-capable router has a small MPLS header inserted between the layer-2 header and the layer-3 header.

The MPLS header contains the label, 3 bits reserved for experimental use, a single S bit that marks the end of a series of stacked MPLS headers, and a TTL field.

**An MPLS header can only be sent between MPLS-capable routers.**

<br/>

### How MPLS Works

An MPLS-capable router forwards an MPLS frame by looking up the MPLS label in its forwarding table and sending the datagram out the appropriate output interface, which is why it's often called a label-switched router.

In other words, an MPLS-capable router doesn't need to extract the destination IP address or perform a longest-prefix match in its forwarding table.

<p align="center"><img width="700" alt="MPLS network" src="https://user-images.githubusercontent.com/76640167/214874093-edf53d76-44dd-4d7e-b228-2c8df445c76b.png">

Let's see how routers interact when only R1 through R4 are MPLS-capable.

1. R1 advertises to R2 and R3 that it can route to destination A, and that frames carrying MPLS label 6 will be forwarded to that destination.
2. R3 advertises to R4 that it can route to destinations A and D, and that incoming frames carrying MPLS labels 10 and 12, respectively, will be switched toward those destinations.
3. …

By repeating this, R4 ends up with three MPLS paths.

MPLS-capable routers **operate without ever touching a packet's IP header**.

<br/>

So MPLS speeds up switching by switching on labels instead of looking at IP addresses.

<br/>

MPLS also helps manage traffic: whereas an IP routing protocol picks just a single least-cost path, MPLS can provide paths that would be impossible with standard IP routing protocols.

This is one simple way MPLS is used to provide **traffic engineering**.
