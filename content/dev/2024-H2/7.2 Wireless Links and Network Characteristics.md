# 7.2 Wireless Links and Network Characteristics

<br/>

Unlike wired links, wireless links come with some extra things to consider.

<br/>

### Decreasing Signal Strength (Path Loss)

- Electromagnetic radiation weakens as it passes through matter.
- Even in free space, the signal disperses,  
  so signal strength decreases as the distance between sender and receiver increases.

This is also called `path loss`.

<br/>

### Interference from Other Sources

- Radio signals **transmitted in the same frequency band** `interfere` with each other.
- Besides interference between senders, electromagnetic noise in the environment (e.g., from a nearby motor or a microwave oven) can also cause interference.

This is one reason recent 802.11 standards operate in the 5 GHz band.

<br/>

### Multipath Propagation

`Multipath propagation` happens when parts of the electromagnetic wave traveling between sender and receiver bounce off objects and the ground,  
taking several paths of different lengths.

This blurs the signal detected at the receiver.

<br/>
<br/>

As you can see from these, **bit errors are much more common on wireless links** than on wired links.

That's why wireless link protocols, including 802.11, use not only `powerful CRC error-detection codes`  
but also `link-level reliable data transfer protocols` that retransmit corrupted frames.

<br/>
<br/>

## SNR, BER

### SNR (Signal-to-Noise Ratio)

> The relative measure of the strength of the received signal compared to the **noise**

- Unit: decibels (dB)  
  (20 times the base-10 logarithm of the ratio of the received signal's amplitude to the noise's amplitude)
- **The larger the SNR, the easier it is for the receiver to extract the intended signal despite the noise.**

<br/>

### Bit Error Rate (BER)

> The probability that a transmitted bit is received in error at the receiver

<br/>
<br/>
<br/>

The figure below shows the relationship between BER and SNR for three modulation techniques over an idealized wireless channel.

<br/>

<br/>
<br/>

### For a Given Modulation Scheme, a Higher SNR Means a Lower BER

That's because when the sender **increases its transmission power**, the SNR goes up,  
and at the same time the probability that a received bit is in error goes down.

However, there's no gain in raising the power beyond a certain threshold.

<br/>

The downsides of increasing transmission power:

- More power means more energy consumed by the sender, which matters a lot for battery-powered mobile users.
- More power can cause more interference with other senders' transmissions.

<br/>

### For a Given SNR, a Modulation Technique with a Higher Bit Rate Has a Higher BER

In the figure above, look at the case **where the SNR is 10 dB**.

- BER of `BPSK modulation` at 1 Mbps = below 10^(-7)
- BER of `QAM16 modulation` at 4 Mbps = 10^(-1)

10^(-1) is far too high an error rate to be practical, so `BPSK modulation` is preferred in this environment.

<br/>

Now look at the case **where the SNR is 20 dB**.

- The BER of `BPSK modulation` at 1 Mbps is so low it doesn't even show up on the chart.
- BER of `QAM16 modulation` at 4 Mbps = 10^(-7)

If a BER of around 10^(-7) is acceptable, then `QAM16 modulation`, with its higher bit rate, is preferred in this environment.

<br/>

*These observations lead to the last characteristic below.*

<br/>

### Dynamic Selection of the Physical-Layer Modulation Technique Can Be Used to Adapt Modulation to Channel Conditions

SNR and BER can change as a result of mobility or changes in the environment.

So `cellular data systems` based on 802.11 Wi-Fi or 4G/5G networks  
allow adaptive selection of a modulation technique that delivers the highest bit rate possible while still meeting an acceptable BER for the given channel conditions.

<br/>
<br/>

## The Hidden Terminal Problem

Suppose A is sending data to B, and C is also sending data to B, as shown below.

<br/>

<p align="center"><img width="350" alt="Hidden terminal problem caused by an obstacle" src="https://user-images.githubusercontent.com/86337233/216113474-f5e1735e-1927-4332-ae9c-af83c6852540.png">

<br/>
<br/>

Even though A's and C's transmissions really do interfere at the destination B,  
environmental obstacles such as mountains or buildings can mean **A and C can't detect each other's transmissions**.

This is called the `hidden terminal problem`.

<br/>
<br/>

## 7.2.1 CDMA

`Code division multiple access (CDMA)` is one of the **channel partitioning protocols**,  
and it's widely used in wireless LAN and cellular technologies.

<details>
<summary>Channel partitioning protocols</summary>
Protocols that keep signals sent by multiple senders from interfering at the receivers when hosts communicate over a shared medium
</details>

<br/>

In a CDMA protocol, each bit being sent is spread and encoded by multiplying it by a signal (the code) that changes at a much faster rate (the `chipping rate`) than the original sequence of data bits.

<br/>
<br/>

Let's look at the simple, idealized CDMA encoding/decoding scenario below.

<br/>

<p align="center"><img width="700" alt="CDMA" src="https://user-images.githubusercontent.com/86337233/216113479-2c195c37-f808-4879-b4ae-b63c5bb390b7.png">

<br/>
<br/>
<br/>

Assume the unit of time is defined by **the rate at which data bits arrive at the CDMA encoder**.

That is, each original data bit to be transmitted takes one `bit slot` of time.

<br/>

Let `di` be the value of the data bit in the i-th bit slot.

For mathematical convenience, a data bit with value 1 is represented as `1`, and a data bit with value 0 as `-1`.

<br/>

Each bit slot is further divided into M mini-slots. (M = 8 in the figure.)

- The **CDMA code** used by the sender is a sequence of M values, `Cm (m = 1, … , M)`.
- Each Cm value is either 1 or -1.

<br/>
<br/>

### ✅ CDMA with Interfering Senders

In reality, there are many senders interfering with each other.

So how can a CDMA receiver recover its sender's original data bits when they're mixed with bits transmitted by other senders?

<br/>

> CDMA works under the assumption that **interfering bit signals transmitted at the same time are additive**.

e.g., if three senders send a 1 in the same mini-slot and a fourth sender sends a -1,  
then the signal received by every receiver in that mini-slot is 2 (= 1+1+1-1).

That covers only the essentials of CDMA; in practice, there are many hard problems.

1. CDMA codes have to be chosen carefully so that a CDMA receiver can pull out a particular sender's signal.
2. Above, we assumed that the signal strengths from different senders were equal at the receiver, but that's rarely the case in real life.
