## Wireless Hosts

Just as in wired networks, `wireless hosts` are **end-system devices that run applications**.

e.g., smartphones, tablets, laptops, IoT (Internet of Things) devices such as sensors, home appliances, cars, and countless other Internet-connected devices

<br/>
<br/>

## Wireless Links

A host connects to a base station or to another wireless host through a `wireless communication link`.

<br/>

In the figure above, wireless links connect hosts at the edge of the network to the network infrastructure in the core.

Wireless links are sometimes also used within the network core to connect network devices such as routers and switches.

<br/>
<br/>

## Base Stations

A `base station` is **responsible for sending and receiving data (e.g., packets)** to and from the wireless hosts associated with it.

In other words, it mediates and coordinates transmissions among the many wireless hosts associated with it.

<br/>

Saying that `a wireless host is "associated" with a base station` means two things:

1. The host is within the wireless communication range of that base station.
2. The host uses that base station to relay data between itself and the larger network.

<br/>

Examples of base stations

- `Cell towers` in cellular networks
- `Access points (APs)` in wireless LANs

<br/>

### Infrastructure Mode

Hosts associated with a base station are said to `operate in infrastructure mode`.

That's because **all the traditional network services**, such as address assignment and routing, **are provided through the base station** to the hosts connected to the network.

<br/>

In contrast, in an `ad hoc network`, wireless hosts have no such infrastructure to connect to.

In that case, the hosts themselves have to provide services such as routing, address assignment, and DNS-like name-to-address translation.

<br/>

### Handoff (Handover)

When a mobile host **moves out of one base station's range and into another's**, it has to change its point of attachment to the larger network (i.e., change the base station it's associated with).

This process is called `handoff` or `handover`.

<br/>
<br/>

## Network Infrastructure

This is the larger network that wireless hosts want to communicate with.

# Types of Wireless Networks

The elements of a wireless network can be combined in many ways to form different kinds of wireless networks.

<br/>

We can broadly classify wireless networks using the following two criteria:

1. Does a packet in the wireless network cross `a single hop` or `multiple hops`?
2. Is there network `infrastructure`, such as a base station, or not?

<br/>

### Single-Hop, Infrastructure-Based

- Has a **base station connected to a larger wired network**.
- All communication happens over a **single wireless hop** between the base station and a wireless host.
- e.g.,
    - `802.11 networks`: used in classrooms, restaurants, libraries, and so on
    - `4G LTE networks`

<br/>

### Single-Hop, Infrastructure-Less

- There's no base station connected to a wired network.
- **One node in the single-hop network can mediate and coordinate the transmissions of the other nodes.**
- e.g., `Bluetooth networks`: connect small wireless devices like keyboards, speakers, and headsets

<br/>

### Multi-Hop, Infrastructure-Based

- There has to be a **base station connected to a larger network**.
- Some nodes have to relay through other wireless nodes to communicate with the base station.
- e.g.,
    - `Some wireless sensor networks`
    - `Wireless mesh networks`

<br/>

### Multi-Hop, Infrastructure-Less

- **There's no base station.**
- Nodes may relay messages through several other nodes to reach a destination.
- Nodes are **mobile**, so connectivity between them can change.
- This kind of network is called a `mobile ad hoc network (MANET)`.

<br/>
<br/>

*The book mostly limits its discussion to single-hop networks and networks with infrastructure.*
