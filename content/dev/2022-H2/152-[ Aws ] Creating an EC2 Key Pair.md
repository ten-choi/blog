Aws platform

#### ? **Overview**

Creating a key pair on the AWS platform

## **\- What Is an AWS Key Pair**

It's the key used to prove your credentials when connecting to an instance in AWS EC2.  

## **\- How to Create One**

Find Key Pairs under the EC2 section in AWS.

![](https://cdn.jsdelivr.net/gh/ten-choi/blog-images@main/dev/tistory/152/img.webp)

Just think a bit about the name, leave the rest as-is, and click Create key pair. That's it.

![](https://cdn.jsdelivr.net/gh/ten-choi/blog-images@main/dev/tistory/152/img_1.webp)

Once a key pair has been downloaded, it's hard to download it again, so store it somewhere safe.
