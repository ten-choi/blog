## **\- Course Direction**

Small-group, personal lessons (I'm thinking 1–2 people for now)  
How to actually run a development process  
A guide on how to study efficiently and get hired as a backend developer  

## **\- Course Process**

1.  Why you want to be a developer and which direction to take
2.  How to use Node and VS Code
3.  Learning JavaScript (call stack, scope, arrow functions, var/let/const, etc.)
4.  Building an HTTP server and using Express
5.  Using MySQL and learning SQL
6.  Working with a database and basic CRUD
7.  Version control with Git
8.  Building a project
9.  Job search guide
