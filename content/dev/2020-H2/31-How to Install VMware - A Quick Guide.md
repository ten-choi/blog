## \- What Is VMware?

It's a utility for running a single virtual machine on a Windows or Linux PC.

Put simply, VMware lets you run another operating system

inside Windows.

[https://www.vmware.com/kr.html](https://www.vmware.com/kr.html)  

That's the official site, and below is what the download page looks like.

![](https://cdn.jsdelivr.net/gh/ten-choi/blog-images@main/dev/tistory/31/img_1.webp)

[https://www.vmware.com/kr/products/workstation-player/workstation-player-evaluation.html](https://www.vmware.com/kr/products/workstation-player/workstation-player-evaluation.html)

You can download it from the URL above.

My computer runs Windows, so I'm using the Windows version.

![](https://cdn.jsdelivr.net/gh/ten-choi/blog-images@main/dev/tistory/31/img_2.webp)

Run the file you downloaded to start the install.

![](https://cdn.jsdelivr.net/gh/ten-choi/blog-images@main/dev/tistory/31/img_3.webp)

The Enhanced Keyboard Driver option is about making keyboard input more reliable, but it doesn't make much difference,

so you can leave it unchecked. Check it if you're curious, haha.

![](https://cdn.jsdelivr.net/gh/ten-choi/blog-images@main/dev/tistory/31/img_4.webp)

If you have enough space, install it on the C drive.

For everything else, just click Next. Nothing special, just keep hitting Next.

![](https://cdn.jsdelivr.net/gh/ten-choi/blog-images@main/dev/tistory/31/img_5.webp)

And that's VMware installed.

Easy enough. Now launch it.

![](https://cdn.jsdelivr.net/gh/ten-choi/blog-images@main/dev/tistory/31/img_6.webp)

If your screen looks like mine, you're done.
