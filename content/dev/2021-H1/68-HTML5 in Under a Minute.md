### **\- What Is HTML?** 

It's a language for describing web pages.

\- Breaking down the acronym -

**\-> HyperText**

Text you can attach links to. Link text like yeolceo.tistory.com, for example!

(My blog link is a fake...)

**\-> Markup**

You place text inside markers, like <div> sentence </div>. That's what a markup language is.

It's a language that represents data on a document using tags.

**\-> Language**

"Language" is added at the end to say it's a language that combines the two ideas above.

In other words!

It's a language that can link between pages and is written in markup, like this:

```html
<html>
    <head>
	   Handles information other than what's shown in the document.
    </head>
    <body>

       <a href="https://yeolceo.tistory.com/">You can link like this to move to another
       page, which is why it's called hypertext.</a>

		This is the part where content appears in the document.

    </body>
</html>
```

The area inside the outlined lines is the document part.

![](https://cdn.jsdelivr.net/gh/ten-choi/blog-images@main/dev/tistory/68/img_1.webp)

And that's HTML explained already!!!

**But here's the thing...**

As HTML evolved quickly, each browser rendered HTML differently, and that became a problem.

So HTML needed a standard, and that's how the HTML5 standard came about.

### **\- What HTML5 Added and Improved**

1\. Tags became more standardized than before. (Search "html5" on Google and the wiki covers it well.)

2\. Local storage: you can store data even offline. (The **Web Storage** section on **w3schools** explains it in detail.)

![](https://cdn.jsdelivr.net/gh/ten-choi/blog-images@main/dev/tistory/68/img_2.webp)

3.  Media and graphics features became easier to use.

video (a video player tag), audio (an audio player tag), canvas (a tag you can draw on like a canvas) - see the **HTML Media** section on **w3schools**

![](https://cdn.jsdelivr.net/gh/ten-choi/blog-images@main/dev/tistory/68/img_3.webp)

4\. You can get the user's geographic location with the **Geolocation API**. - see the **Geolocation API** section on **w3schools**

![](https://cdn.jsdelivr.net/gh/ten-choi/blog-images@main/dev/tistory/68/img_4.webp)

The sites I point you to are for anyone who wants more detail.
