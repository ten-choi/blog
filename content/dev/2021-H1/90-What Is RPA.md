### **What Is RPA?**

**RPA (Robotic Process Automation)** is technology that uses software robots to automate business tasks.

Put simply, it records the process of a task you do on a computer so you can **reuse** it whenever you need.

There are programs like **UiPath** that stand out in the **global RPA market**.

Let's take an example using that program.

Say you use data from Excel to log in with an **RPA program**:

**\[** pick the Excel file (with URL, ID, PW) -> extract the data -> open the site at that URL -> enter ID and PW ->

click the login button -> login complete **\]**      

You can build a process like that, and once you build and save it, next time

you can run the whole process with a single click.

Rather than a brand-new technology, I think **RPA** is where we ended up as technology advanced

and everyone kept calling for **automating** the things people do by hand.
