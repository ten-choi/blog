#### **\[Compiled Languages vs. Interpreted Languages\]** 

  \- Knowing what the English words mean makes this much easier to understand. -

#### **What Is a Compiled Language?**

A language where, to run **your code**, the whole program is first translated into **machine code** by a **compiler**, which produces a **file**, and then that **file** is executed.

A **compiler** is a program that translates a programming language into another language; tools like Visual Studio and Eclipse include one.

If **compiling** takes 4 hours and there's an **error**, you have to fix it and **compile** for another 4 hours to check it.

But for **correctly written code**, the **execution speed** after compiling is faster than that of an **interpreted language**.

Typical examples are **C, C++, Java, C#, and Go**.

![](https://cdn.jsdelivr.net/gh/ten-choi/blog-images@main/dev/tistory/73/img-png.webp)

#### **What Is an Interpreted Language?**

A language that doesn't convert **your code** into **machine code** up front, but interprets and executes it line by line.

It runs slower than compiled code. But when an error occurs, you can fix it and run it right away, with no separate compile time.

Typical examples are **Python, Ruby, and JavaScript**.

(If you look into JIT compilers, JavaScript turns out to be a bit different. If you work with Node.js, it's worth looking into at some point. V8, for example...)

![](https://cdn.jsdelivr.net/gh/ten-choi/blog-images@main/dev/tistory/73/img_1.webp)

Think of it as building background knowledge — just knowing this distinction exists is enough.

I hope this was **easy** to understand. Happy coding!
