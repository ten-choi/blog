#### **\-PuTTY**

서버에 접속할 때 물리적 단말기가 아닌 윈도 등의 운영체제에서 가상의 단말기를 사용하여

ssh, Telnet, raw tcp 방식으로 원격 접속을 제공하는 **무료 응용프로그램**입니다.

단말기 -> 컴퓨터 등의 시스템에서 데이터를 입력하고 표시하는 데 사용되는 전자기기를 말합니다.

#### **\-다운로드 방법**

**putty**를 구글에서 검색해줍니다. (구글 선생님은 다 알려주십니다)

![](https://cdn.jsdelivr.net/gh/ten-choi/blog-images@main/dev/tistory/72/img_1.webp)

해당 사이트를 접속하면 아래와 같은 화면이 뜹니다. 화살표를 클릭해주세요

![](https://cdn.jsdelivr.net/gh/ten-choi/blog-images@main/dev/tistory/72/img_2.webp)

아래와 같은 화면이 잘 나오셨나요? 빨간 줄로 위치를 표시했습니다. (한 칸 더 내려가시면 이미지 더 확대해놨습니다)

![](https://cdn.jsdelivr.net/gh/ten-choi/blog-images@main/dev/tistory/72/img_3.webp)

일반적으로 윈도우를 쓰신다면 **64bit putty.exe**를 클릭해서 다운로드해주세요.

![](https://cdn.jsdelivr.net/gh/ten-choi/blog-images@main/dev/tistory/72/img_4.webp)

#### **\-사용법**

![](https://cdn.jsdelivr.net/gh/ten-choi/blog-images@main/dev/tistory/72/img_5.webp)

1\. **putty**에서 통신과관련된 세부적인 기능들입니다. (이곳을 건드릴 일은 아직 없었습니다.) 

2 본인이 접속해야 할 ip와 port를 입력합니다. (대상 서버의 **방화벽**에서 **port**가 열려있어야합니다.)

3\. 상태에서 오픈을 누릅니다. (일반적으로 **ssh**로 접속합니다.)
