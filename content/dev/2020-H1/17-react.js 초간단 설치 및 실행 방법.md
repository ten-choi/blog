node.js를 사용하고 에디터는 atom을 사용합니다. (ide 다른 거 쓰셔도 무방합니다.)

Node.js®는 [Chrome V8 JavaScript 엔진](https://v8.dev/)으로 빌드된 JavaScript 런타임입니다.

javaScript 개발을 위한 환경이라는 의미입니다.

react.js 도 js 이기때문에 [https://nodejs.org/ko/](https://nodejs.org/ko/)

다운로드하여주셔야 합니다. 

npm 은 자바스크립트 프로그래밍 언어를 위한 패키지 관리자인데 node.js 다운로드하여주셔야 사용할 수 있습니다.

환경변수 설정은 필수는 아니지만 해주시면 편합니다.

자 이제 react를 만들어 봅시다 방법은 아주 간단합니다.

[https://www.npmjs.com/package/create-react-app](https://www.npmjs.com/package/create-react-app)

c드라이브 라면 원하는 폴더의 주소를 복사하고 cmd에서       C:\\user\\어쩌고> cd (원하는 경로) 

![](https://cdn.jsdelivr.net/gh/ten-choi/blog-images@main/dev/tistory/17/img.webp)

이상태로 만드시고 엔터 누르시면 react create app  말 그대로 react를 만들어줄 라이브러리입니다.

i는 install의 약자입니다. create-react-app (원하는 프로젝트명)을 설정하고 엔터키를 눌러줍시다.

저는 test라는 이름의 프로젝트를 create 하였습니다.

![](https://cdn.jsdelivr.net/gh/ten-choi/blog-images@main/dev/tistory/17/img_1.webp)

저와 같은 atom이시라면 이제 atom을 실행해줍시다. 

![](https://cdn.jsdelivr.net/gh/ten-choi/blog-images@main/dev/tistory/17/img_2.webp)

src 폴더의 app.js를 클릭한다면 저화 같은 화면이 출력될 것입니다. 

이제 실행해볼 차례입니다.

명령 프롬프트 (cmd) 를실행합니다.

![](https://cdn.jsdelivr.net/gh/ten-choi/blog-images@main/dev/tistory/17/img_3.webp)

자신이 설치한 project 경로에서 npm start 명령어를 입력합니다.

react를 실행하는 명령어입니다. 

![](https://cdn.jsdelivr.net/gh/ten-choi/blog-images@main/dev/tistory/17/img_4.webp)

축하드립니다. 문제없이 저와 같은 화면이 출력되셨다면 성공입니다.
