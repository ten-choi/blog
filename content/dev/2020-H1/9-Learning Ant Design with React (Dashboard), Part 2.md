**I'm going to use components from the Ant Design site.**

**After all, the whole point of using Ant is not having to write them myself.**

The URL below is the page you land on when you click Components on the Ant site. Button is the first one listed.

[https://ant.design/components/button/](https://ant.design/components/button/)

Scroll down and you'll see examples.

![](https://cdn.jsdelivr.net/gh/ten-choi/blog-images@main/dev/tistory/9/캡처.webp)

If you don't see the code, click the </> icon to reveal it.

If you installed the React app as described in the previous post, you'll have an App.js file.

We'll copy and paste the code lines from the site.

Delete what's inside, copy everything from <div> to </div> in the image above, and put it inside return().

Of course, copy and paste the imports at the top as well.

Then, in the Command Prompt, go to where you installed the app and run npm start.

![](https://cdn.jsdelivr.net/gh/ten-choi/blog-images@main/dev/tistory/9/222.webp)

![](https://cdn.jsdelivr.net/gh/ten-choi/blog-images@main/dev/tistory/9/111처.webp)

**Congrats! You've built a simple button UI just by copying and pasting an import and a <div>.**
