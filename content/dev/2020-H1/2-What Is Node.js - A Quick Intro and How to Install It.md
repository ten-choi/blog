## **What Is Node.js?**

**Node.js is a runtime that lets you run JavaScript outside the web browser, using the V8 engine.**

\- What V8 does: Node.js hands your JavaScript to the V8 engine, which compiles it into machine code. JavaScript is written for humans, and a computer can't understand it until it's translated into machine code.

## **How to Install It**

Search for **Node.js**, or go straight to the official site:

[https://nodejs.org/en/](https://nodejs.org/en/)

Installing **Node.js** also installs **npm**.

**npm** stands for **Node Package Manager**. It's the tool that manages packages written for **Node.js**.

If you're just learning, grab the latest version. For real projects, go with the stable (**LTS**) version.

![](https://cdn.jsdelivr.net/gh/ten-choi/blog-images@main/dev/tistory/2/img_1.webp)

Run the installer you downloaded and click through the steps.

Once your environment variables are set, check the installed versions with `npm -v` or `node -v`.

(If the environment variables weren't set automatically, see [https://yeolceo.tistory.com/3](https://yeolceo.tistory.com/3).)

![](https://cdn.jsdelivr.net/gh/ten-choi/blog-images@main/dev/tistory/2/img_2.webp)

That's a quick look at what Node.js is and how to install it. Happy coding!
