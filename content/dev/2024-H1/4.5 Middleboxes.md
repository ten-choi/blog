# 4.5 Middleboxes

Definition of a middlebox
> 💡 Any intermediary box performing functions apart from the normal, standard functions of an IP router on the data path between a source host and a destination host

Broadly, we can identify three types of services that middleboxes perform:
- NAT translation: NAT boxes implement private network addressing, rewriting datagram header IP addresses and port numbers.
- Security services: Firewalls block traffic based on header field values or redirect packets for additional processing, such as DPI (Deep Packet Inspection). Intrusion detection systems (IDS) can detect predetermined patterns and filter packets accordingly.
- Performance enhancement: Middleboxes perform services such as caching and compression, and also handle load balancing, distributing requests across one of a set of servers that can provide the desired service.

Middleboxes clearly violate the traditional layer separation that strictly distinguished the network, transport, and application layers.

For example, a NAT box sitting between a router and a host rewrites network-layer IP addresses and transport-layer port numbers.

An in-network firewall inspects datagrams by looking not only at IP datagram headers but also at application-layer and transport-layer headers.

Some people consider middleboxes architecturally undesirable, while others have adopted the philosophy of accepting them as "important and permanent."
