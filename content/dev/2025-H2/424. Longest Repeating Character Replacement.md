# LeetCode 424. Longest Repeating Character Replacement

> **Difficulty**: Medium | **Pattern**: Sliding Window
> https://leetcode.com/problems/longest-repeating-character-replacement/

## Problem Summary

You're given a string `s` and an integer `k`. If you can change a character to any other uppercase letter at most `k` times,
return the length of the **longest substring made up of a single repeated character**.

## Key Idea

A window is valid when:

````
(window length) - (count of the most frequent character in the window) <= k
````

- The optimal move is to keep the most frequent character and change all the others
- If the number of those "others" exceeds `k`, shrink the window from the left

## Solution (Java)

````java
public int characterReplacement(String s, int k) {
    int[] count = new int[26];  // count of each character in the window
    int left = 0;
    int maxCount = 0;           // count of the most frequent character in the window
    int answer = 0;

    for (int right = 0; right < s.length(); right++) {
        // 1. Add the right character to the window
        maxCount = Math.max(maxCount, ++count[s.charAt(right) - 'A']);

        // 2. If the window is invalid (characters to change > k), shrink from the left
        if (right - left + 1 - maxCount > k) {
            count[s.charAt(left) - 'A']--;
            left++;
        }

        // 3. Update the answer with the current window length
        answer = Math.max(answer, right - left + 1);
    }

    return answer;
}
````

## Example Run

`s = "AABABBA"`, `k = 1`

| Step | Window | Length | maxCount | Chars to change | Valid? |
|------|--------|------|----------|--------------|-------|
| 1~4  | `AABA` | 4 | 3 (A) | 1 | ✅ |
| 5    | `AABAB` | 5 | 3 | 2 | ❌ → left++ |
| 5'   | `ABAB` | 4 | 3 | 1 | ✅ (slide) |

→ Final answer: **4**

## Complexity

- **Time**: O(N) — the `left` and `right` pointers each move at most N times
- **Space**: O(1) — a fixed array of 26 slots for uppercase letters

## Interview Points

1. **Why `maxCount` doesn't need updating when the window shrinks**
    - The answer is "the largest window length ever seen," so even if `maxCount` stays at a past maximum,
      the window never grows incorrectly
    - For the window to grow again, a new most-frequent character has to exceed the existing `maxCount`
2. **Why `if` is enough instead of `while`**
    - The window only needs to slide one step at a time while keeping its max size, so shrinking once is enough
3. **Related problems**: 3. Longest Substring Without Repeating Characters, 76. Minimum Window Substring
