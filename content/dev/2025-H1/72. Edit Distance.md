72. Edit Distance

Input: word1 = "horse", word2 = "ros"
Output: 3

```kotlin
class Solution {
    fun minDistance(word1: String, word2: String): Int {
        val m = word1.length   // set the length
        val n = word2.length   // set the length
        val dp = Array(m + 1) { IntArray(n + 1) }  // create a 2D array

        // Initialization: when word1 is empty, the result of inserting up to word2
        for (i in 0..m) {
            dp[i][0] = i
        }

        // Initialization: when word2 is empty, the result of only deleting from word1
        for (j in 0..n) {
            dp[0][j] = j
        }
        // Up to here it's manageable and easy to understand


        // Fill the DP table
        for (i in 1..m) {              // m = 5 / Input: word1 = "horse", word2 = "ros"
            for (j in 1..n) {          // n = 3
                if (word1[i - 1] == word2[j - 1]) { // If the characters match, no delete, insert, or replace below is needed
                    dp[i][j] = dp[i - 1][j - 1]   // Comparing index 0, 0 is correct because character handling in dp starts at 1
                } else {
                    // Since the calculation starts from 0,0, we store the computed value in dp[i][j]
                    // We store the smallest value because i and j record that this action was taken: of the 3 methods, we take the one with the lowest number
                    // That value then applies to i and j; once 1, 1 is filled in, it's used again in later calculations and accumulates

                    // e.g. i=1, j=2
                    dp[i][j] = 1 + minOf(
                        dp[i - 1][j],    // Delete: delete the current character from word1
                        dp[i][j - 1],    // Insert: insert word2's current character into word1
                        dp[i - 1][j - 1] // Replace: replace word1's current character with word2's current character
                    )
                }
            }
        }

        return dp[m][n]
    }
}
```

## Why the 3 Operations Are Needed

Edit Distance uses 3 basic operations to transform a string:

### 1. Delete - `dp[i-1][j]`

- **Meaning**: delete the current character from word1
- **Example**: "horse" → "orse" (delete h)
- **DP view**: the cost of matching word1 up to i-1 with word2 up to j, plus 1

### 2. Insert - `dp[i][j-1]`

- **Meaning**: insert word2's current character into word1
- **Example**: "ros" → "rose" (insert e)
- **DP view**: the cost of matching word1 up to i with word2 up to j-1, plus 1

### 3. Replace - `dp[i-1][j-1]`

- **Meaning**: replace word1's current character with word2's current character
- **Example**: "horse" → "rorse" (replace h with r)
- **DP view**: the cost of matching word1 up to i-1 with word2 up to j-1, plus 1

## A Concrete Example

With `word1 = "horse"`, `word2 = "ros"`, take dp[2][2] (matching "ho" from word1 with "ro" from word2):

```
word1[1] = 'o', word2[1] = 'o'
→ they match, so dp[2][2] = dp[1][1] = 1
```

If they were different:

```
Suppose word1[1] = 'o', word2[1] = 's':

1. Delete: dp[1][2] + 1 = cost of matching "h" and "ro" + delete 'o'
2. Insert: dp[2][1] + 1 = cost of matching "ho" and "r" + insert 's'
3. Replace: dp[1][1] + 1 = cost of matching "h" and "r" + replace 'o' with 's'

Pick the minimum of these!
```

## Why Are These 3 Enough?

Because every possible string edit can be expressed with these 3 operations:

- **When the characters differ**: deleting, inserting, or replacing are the only options
- **Optimal solution for each operation**: builds on the optimal solutions of previous states (the core of dynamic programming)
- **Pick the minimum**: choose the cheapest of the 3
