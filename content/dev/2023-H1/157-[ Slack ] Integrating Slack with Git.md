#### ? **Environment** 

Slack Client

#### ? **Overview**

If your company uses Slack, you can connect it to Git and automate notifications.

## **\- How to Use**

Click the Add apps button at the bottom left of Slack.  
Then search for and add the GitHub app.

![](https://cdn.jsdelivr.net/gh/ten-choi/blog-images@main/dev/tistory/157/img_2.webp)

![](https://cdn.jsdelivr.net/gh/ten-choi/blog-images@main/dev/tistory/157/img_3.webp)

Click the Connect account button and log in to the account you want to connect.

![](https://cdn.jsdelivr.net/gh/ten-choi/blog-images@main/dev/tistory/157/img.webp)

Type the command below in the GitHub app you added, and it will list the available commands.  
/github help

![](https://cdn.jsdelivr.net/gh/ten-choi/blog-images@main/dev/tistory/157/img_1.webp)

Following those commands, you can subscribe to or unsubscribe from a Git repo.  
You'll get notified of changes in the projects you subscribe to,  
such as when someone opens an issue or a PR.

Use the other features as needed.
