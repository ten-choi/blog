# 모노토닉 스택(Monotonic Stack) 명확하게 이해하기

## 정의

모노토닉 스택은 **스택 내부 원소가 항상 오름차순 또는 내림차순을 유지하도록 관리하는 스택**입니다.

별도의 자료구조가 아닙니다. 일반 스택에 규칙 하나를 추가한 것입니다. 여기까지만 들어도 너무 쉽습니다

> push하기 전에, 정렬 순서를 깨뜨리는 원소를 스택에서 전부 pop한다. 그 다음 push한다.

## 어떤 문제를 푸는가

배열의 각 원소에 대해 다음을 구하는 문제입니다.

- **다음 큰 원소**: 오른쪽에서 자기보다 큰 첫 번째 원소
- **다음 작은 원소**: 오른쪽에서 자기보다 작은 첫 번째 원소
- **이전 큰/작은 원소**: 왼쪽 방향으로 같은 질문

이중 반복문으로 풀면 O(N²)입니다. 모노토닉 스택은 이걸 O(N)에 풉니다
데이터양이 늘어날수록 이런 효율을 따지는게 중요합니다


## 동작 원리

"다음 큰 원소" 문제로 설명합니다. 규칙은 두 개뿐입니다.

1. 배열을 왼쪽부터 순회한다. 스택에는 **아직 답을 못 찾은 원소의 인덱스**를 넣는다.
2. 새 원소 `x`가 스택 top의 값보다 크면 → top의 답은 `x`다. **답이 확정됐으니 pop**한다. top이 `x`보다 크거나 스택이 빌 때까지 반복한 뒤, `x`를 push한다.

`[2, 1, 4, 3]`으로 직접 따라가 보겠습니다. (스택에는 인덱스를 넣지만, 이해를 위해 값으로 표기)

| 단계 | 현재 값 | 동작 | 스택 (bottom→top) | 확정된 답 |
| --- | --- | --- | --- | --- |
| 1 | 2 | 스택 비어있음 → push | [2] | |
| 2 | 1 | 1 < 2 → 그냥 push | [2, 1] | |
| 3 | 4 | 4 > 1 → pop, 4 > 2 → pop, push | [4] | 1→4, 2→4 |
| 4 | 3 | 3 < 4 → 그냥 push | [4, 3] | |
| 끝 | | 스택에 남은 원소는 답 없음 | | 4→-1, 3→-1 |

결과: `[4, 4, -1, -1]`

여기서 두 가지를 확인할 수 있습니다.

- 스택은 항상 내림차순(4, 3)을 유지합니다. 순서를 깨는 원소는 push 전에 제거되기 때문입니다.
- **pop된 원소는 그 순간 답이 확정됩니다.** 다시 볼 필요가 없습니다.

## 왜 O(N)인가

각 원소는 정확히 한 번 push되고, 최대 한 번 pop됩니다. 따라서 전체 연산 횟수는 최대 2N번입니다. while문이 중첩되어 있어도 O(N²)이 아닙니다.
이게 처음엔 뭔소린가 싶으니까 이해하기위해 몇번 봐야합니다


## 구현

```python
def next_greater(nums):
    n = len(nums)
    result = [-1] * n   # 답이 없으면 -1
    stack = []          # 인덱스를 저장

    for i in range(n):
        # 스택 top의 답이 nums[i]로 확정되는 동안 pop
        while stack and nums[stack[-1]] < nums[i]:
            idx = stack.pop()
            result[idx] = nums[i]
        stack.append(i)

    return result

print(next_greater([2, 1, 4, 3]))  # [4, 4, -1, -1]
```

값이 아니라 **인덱스를 저장**하는 이유: 문제에서 "몇 칸 뒤에 있는가"를 물으면 인덱스가 필요합니다. 값은 `nums[인덱스]`로 언제든 꺼낼 수 있으므로 인덱스 저장이 항상 더 유연합니다.


## 응용: 일일 온도 (LeetCode 739)

각 날짜에 대해 "더 따뜻한 날이 며칠 뒤에 오는가"를 구하는 문제입니다. 위 코드에서 답으로 넣는 값만 `nums[i]` 대신 `i - idx`(인덱스 차이)로 바꾸면 끝입니다.

```python
def daily_temperatures(temps):
    answer = [0] * len(temps)
    stack = []

    for i, t in enumerate(temps):
        while stack and temps[stack[-1]] < t:
            idx = stack.pop()
            answer[idx] = i - idx   # 며칠 뒤인지
        stack.append(i)

    return answer
```

## 방향 정리

찾으려는 것과 스택의 정렬 방향은 **반대**입니다.

| 찾으려는 것 | 유지하는 스택 | pop 조건 |
| --- | --- | --- |
| 다음/이전 **큰** 원소 | **내림차순** 스택 | `stack top 값 < 현재 값` |
| 다음/이전 **작은** 원소 | **오름차순** 스택 | `stack top 값 > 현재 값` |

외울 필요 없이 pop 조건에서 도출됩니다. "큰 원소를 찾는다" = "현재 값이 더 클 때 pop한다" = 작은 값들이 제거되므로 스택에는 큰 값 순서(내림차순)만 남습니다.

## 주의할 점

- **`<` vs `<=`**: 같은 값을 답으로 인정하는지에 따라 부등호가 달라집니다. 문제 조건을 확인하세요.
- **순회 종료 후 스택에 남은 원소**: 답이 없는 원소들입니다. `-1`이나 `0` 등 문제가 요구하는 기본값으로 두면 됩니다.

## 정리

- 배열에서 "다음/이전으로 크거나 작은 원소"를 찾는 문제 → 모노토닉 스택.
- 규칙: 새 원소가 스택의 정렬을 깨면, 깨지는 원소들을 pop하면서 답을 확정한다.
- 각 원소는 push 1회, pop 최대 1회 → O(N).
