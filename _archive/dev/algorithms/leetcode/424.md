# LeetCode 424. Longest Repeating Character Replacement

> **난이도**: Medium | **패턴**: Sliding Window
> https://leetcode.com/problems/longest-repeating-character-replacement/

## 문제 요약

문자열 `s`와 정수 `k`가 주어진다. 최대 `k`번 문자를 다른 대문자로 바꿀 수 있을 때,
**같은 문자로만 이루어진 가장 긴 부분 문자열**의 길이를 반환한다.

## 핵심 아이디어

윈도우가 유효할 조건:

````
(윈도우 길이) - (윈도우 내 최빈 문자 개수) <= k
````

- 가장 많이 등장한 문자를 남기고 나머지를 전부 바꾸는 것이 최적
- 그 "나머지" 개수가 `k`를 초과하면 윈도우 왼쪽을 축소

## 풀이 코드 (Java)

````java
public int characterReplacement(String s, int k) {
    int[] count = new int[26];  // 윈도우 안의 각 문자 개수
    int left = 0;
    int maxCount = 0;           // 윈도우 안에서 가장 많이 등장한 문자의 개수
    int answer = 0;

    for (int right = 0; right < s.length(); right++) {
        // 1. 오른쪽 문자를 윈도우에 추가
        maxCount = Math.max(maxCount, ++count[s.charAt(right) - 'A']);

        // 2. 윈도우가 유효하지 않으면 (바꿔야 할 문자 수 > k) 왼쪽 축소
        if (right - left + 1 - maxCount > k) {
            count[s.charAt(left) - 'A']--;
            left++;
        }

        // 3. 현재 윈도우 길이로 답 갱신
        answer = Math.max(answer, right - left + 1);
    }

    return answer;
}
````

## 동작 예시

`s = "AABABBA"`, `k = 1`

| 단계 | 윈도우 | 길이 | maxCount | 바꿀 문자 수 | 유효? |
|------|--------|------|----------|--------------|-------|
| 1~4  | `AABA` | 4 | 3 (A) | 1 | ✅ |
| 5    | `AABAB` | 5 | 3 | 2 | ❌ → left++ |
| 5'   | `ABAB` | 4 | 3 | 1 | ✅ (슬라이드) |

→ 최종 답: **4**

## 복잡도

- **시간**: O(N) — `left`, `right` 포인터가 각각 최대 N번 이동
- **공간**: O(1) — 대문자 26칸 고정 배열

## 면접 포인트

1. **`maxCount`를 윈도우 축소 시 갱신하지 않아도 되는 이유**
    - 답은 "역대 최대 윈도우 길이"이므로, `maxCount`가 과거 최대값으로 남아 있어도
      윈도우가 잘못 커지는 일은 없다
    - 윈도우가 다시 커지려면 기존 `maxCount`를 넘는 새로운 최빈 문자가 나와야 함
2. **`while` 대신 `if`로 충분한 이유**
    - 윈도우는 최대 크기를 유지한 채 한 칸씩 슬라이드만 하면 되므로 한 번만 축소하면 됨
3. **연관 문제**: 3. Longest Substring Without Repeating Characters, 76. Minimum Window Substring
