## 3. Java 필수 스니펫 (OA 시간 절약)

- PriorityQueue + Comparator: `new PriorityQueue<>((a,b) -> b - a)`
- Deque를 스택/큐로: `ArrayDeque<Integer> dq = new ArrayDeque<>()`
- 정렬 + 람다: `Arrays.sort(arr, (a,b) -> a[0] - b[0])`
- StringBuilder: `sb.append() / sb.reverse() / sb.deleteCharAt()`
- HashMap 빈도: `map.merge(key, 1, Integer::sum)`
- 비트: `n & (n-1)` (최하위 1비트 제거), `n & 1` (홀짝), `Integer.bitCount(n)`

## 4. 엣지 케이스 체크리스트 (PayPay 후기에서 강조된 부분)

- 빈 배열 / 요소 1개 / 전부 동일값
